Accessibility basics

  • Use labels and text—not colour alone—to communicate meaning.
  • Browser zoom and operating-system screen readers can be used.
  • Images/diagrams added by the admin should include descriptive alt text.
  • Choose whichever contrast theme feels comfortable; preferences vary.
